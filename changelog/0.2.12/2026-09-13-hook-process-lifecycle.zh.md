# 钩子取消会等待进程清理完成

- **日期：** 2026-09-13
- **类型：** fix
- **范围：** `core`

[English](2026-09-13-hook-process-lifecycle.md)

脚本钩子在取消或超时时，会终止 POSIX 进程组或 Windows 上仍存活的进程树，并等待输出管道关闭后再返回中断结果，避免调用方在钩子仍占用工作目录时删除该目录。输入会在启动进程前完成序列化；序列化期间收到取消信号也会阻止执行。

需要读取输出的命令测试改为等待完成状态或可观察的就绪状态。继承管道的回归测试仍保留两秒的排空上限，但从前台输出到达后开始计时，避免冷启动 shell 的耗时影响测量。
