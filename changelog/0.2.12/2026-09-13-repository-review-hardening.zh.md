# 仓库审查强化启动、无障碍、依赖与发布流程

- **Date:** 2026-09-13
- **Type:** fix
- **Scope:** `core`, `web`, `server`, `ci`, `tooling`

[English](2026-09-13-repository-review-hardening.md)

本次发布审查修正了前端启动与键盘交互，更新测试工具链，并为 npm 注册表响应处理补上回归测试。

## 网络工具边界

- 远程图片读取改用现有 HTTP 客户端，验证目标地址、固定 DNS 解析结果并重新验证重定向。在缓存完整图片之前，流式字节限制已生效。
- 超大 HTTP 响应通过正常错误路径拒绝，包括根据声明长度提前拒绝的响应。
- 搜索失败时报告已配置 SearXNG 的错误，不再静默地将查询发送给其他服务商。

## Web 启动与恢复

- 路由模块改为按需加载，并配有可见的加载状态和可重试的错误边界；初始 JavaScript 入口包因此缩小，模块加载失败时也有恢复入口。
- 安装范围协调等待服务器时显示本地化状态，不再留下空白页面。
- 身份验证初始化会区分无效会话与网络或服务器故障。确认收到 `401` 时仍进入登录页；其他故障保留当前会话状态，并允许重试。

## 键盘与状态反馈

- 共用选择菜单新增轮转式焦点、方向键、Home、End 与 Escape 操作，跳过禁用选项，并明确关联触发按钮与列表框。
- 移动端底部面板打开时把焦点移入面板，将 Tab 导航限制在面板内，并在关闭后把焦点还给打开它的控件。
- Toast 错误采用即时播报，信息与成功结果采用礼貌播报，同时保留键盘可操作的关闭按钮。

## 发布与依赖检查

- npm 发布会校验注册表版本列表的 Schema；连接失败或响应格式异常会终止发布，不再被当成可以发布的依据。
- CI 覆盖注册表响应分类，包括精确版本匹配、版本缺失与无效载荷。
- 测试工具链升级至 Vitest 4.1.11。更新后的待发布 lockfile 未报告已知依赖安全公告。
