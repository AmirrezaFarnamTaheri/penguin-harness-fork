# 发布流程拒绝不安全标签与注册表故障

- **Date:** 2026-09-13
- **Type:** process
- **Scope:** `ci`, `tooling`

[English](2026-09-13-release-publishing-hardening.md)

发布标签值已从 shell 脚本的行内插值移至步骤环境变量；npm 发布流程现在能够区分尚未发布的版本、注册表请求失败和响应格式错误。

## 细节

- 发布构建和 npm 版本写入会在缺少标签时明确失败。
- 重试发布时，已存在的软件包版本仍会被安全跳过。
- 注册表连接或响应错误会终止发布，不再被误判为缺少软件包版本。
