# PenguinHarness Fork 0.2.17

此版本整合了自 v0.2.16 以来完成的 Bug Swarm 修复和后续正确性改进，提升 Agent 运行时、模型服务商处理、沙箱边界、Web 座舱和发布工具的可靠性。

## 变更

- 加强 Agent 与文件系统行为，涵盖 Shell 退出状态、畸形输入、路径处理、代码图重新索引和已删除目录，并为发现的边界情况补充回归覆盖。
- 改进 LLM 配额与限流分类、密钥冷却和轮换、定价数据、上下文计量、工具调用标识及推测解码行为。
- 收紧沙箱出口流量与提权处理、凭据脱敏、不可信内容边界和审计行为。
- 防止项目或语言环境切换后到达的旧 Web 请求覆盖新状态。改进聊天恢复、压缩、安装作用域的浏览器状态、移动端警告与审批布局，以及座舱中的 Agent 交接动态。
- 改进 CLI 中断处理、参数验证和语言 Shell 错误报告。
- 加强发布标签验证、生成接口检查、基准数据验证、安装器测试、文档和跨平台测试覆盖。

## 范围说明

这是 Fork 版本。桌面安装包未经签名。Fork 工作流不会发布上游 npm 包、OSS 镜像或 Docker 镜像。

## 安装

请下载此 Fork 的 GitHub Release 构件，适用于 Linux 或 macOS（x64/arm64）以及 Windows（x64）。平台归档包含所需运行环境；通用归档需要 Node.js 24 或更高版本。
