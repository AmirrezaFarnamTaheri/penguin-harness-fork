PenguinHarness fork 0.2.15 修正了上下文占用统计与智能体归属显示，并将更多 Cockpit 面板接入项目的实时数据。

## 变更

- 上下文徽标单独显示最近一次请求的实测占用，不再与提示词组成估算或会话累计用量混淆。
- 界面显示智能体名称与描述。提示词、引导消息和文件编辑保留其智能体归属。
- Guardian 展示经过 HMAC 验证的工具执行回执，分别标明所属会话与实际执行会话。缺少执行来源信息的旧回执会显示为未知。
- 协作面板展示实时邮箱队列、任务交接与共识状态，标签和对话框支持中文及英文。
- 任务看板支持 TOML 定时任务管理。轨迹检查、快照归档、记忆搜索、回放控件和机器健康面板使用各自的运行时数据源。
- 跨智能体会话恢复后保留已配置的子智能体模型级联策略，组合模型目标也保留其配置层级。普通子会话仍受一层子智能体深度限制。
- 新增回归测试覆盖项目隔离、轨迹身份、循环检测、接口签名、窄屏布局和双语字典一致性。

## 范围说明

桌面预发布更新需通过 `PENGUIN_UPDATE_ALLOW_PRERELEASE` 明确启用；本版本未提供命名的 stable/canary 通道切换。工作流画布与查询分区视图为只读。落地页基准测试声明仍因缺少来源证明而被阻止发布，本说明不作新的性能声明。

## 安装

请下载此 Fork 的 GitHub Release 构件，适用于 Linux 或 macOS（x64/arm64）以及 Windows（x64）。平台归档包含所需运行环境；通用归档需要 Node.js 24 或更高版本。Fork 桌面构建未经签名。此 Fork 不发布上游 npm 包、OSS 镜像或 Docker 镜像。
