# 在 Web App 中展示 Jev 顾问观察与协作活动

- **Date:** 2026-09-25
- **Type:** feature
- **Scope:** `web`, `docs`

[English](2026-09-25-jev-coordination-activity.md)

Web App 现在会渲染 [Jev 顾问](2026-09-25-jev-advisory.zh.md)发出的观察结果，智能体停靠栏还新增了**活动**标签页，把这些观察按时间顺序排在真正产生它们的记录旁边。两处都读取既有事件流，因此既不重复拉取，也不凭空生成内容。

## 细节

- `jev_advisory` hook 事件会成为事件流模型中一个带类型的条目；其他 hook 名称或格式不合法的载荷仍按原样忽略。该条目不带任何 decision 字段，因此在界面上绝不会被误认为审批结果。
- 顾问卡片显示状态、工具匹配、置信度、风险、需审批概率、延迟、令牌、模型与有界原因；顾问没有产出时只显示暂不可用。卡片在两种语言下都明写该观察仅供参考。
- **活动**标签页在所选会话及其嵌套模型上，按事件流顺序汇集顾问观察、工具记录、父 Agent 引导消息与子会话事件。它不会把顾问观察挂到它并未指名的工具下，日志使用语义化的 `role="log"` 实时区域，更新会被播报而不会打断阅读。
- 该标签页沿用停靠栏既有的窄屏与桌面端展示行为；切换 Session 后回到**对话**标签页。
