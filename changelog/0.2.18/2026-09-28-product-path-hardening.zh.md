# 跨层审查后的产品路径加固

- **Date:** 2026-09-28
- **Type:** fix
- **Scope:** `core`, `server`, `web`, `cli`, `desktop`

[English](2026-09-28-product-path-hardening.md)

后续审查修复了产品实际运行路径中的问题，并为包边界和进程边界的故障补充了回归覆盖。

## 细节

- 研究验证会在工作开始前预留预计 Token 成本，并在成功或失败时保守结算。资源释放会检查当前进程所有权、串行化并发操作，并避免将过期的扫描结果应用到已替换的资源。
- Provider 健康状态更新携带一次性选择凭据，避免较早完成的异步结果覆盖较新的状态。Cockpit 实时流出现间隙时，会从最后一个连续游标恢复事件。
- 图片文件扩展名受支持但无法从文件头验证尺寸时，读取操作会拒绝解码。Shell 命令识别会保留引号内的运算符，并正确处理 Windows 路径。
- ACP 传输代次将已退役连接与替换连接隔离。服务端事件载荷会保留分配的序列号，并正确统计 UTF-8 字节数。
- CLI 生命周期处理、无障碍交互、文件预览、日历与工单控件、会话恢复和工具摘要显示均进行了针对性修正。
