## Candidates checked and not changed

- Frame parser partial-marker regex: already anchored with `(?:^|\n)`; the cross-chunk test covers it.
- Docs-claims heading slugs: GitHub's slugger does not collapse repeated whitespace, so the
  existing `\s` → `-` mapping matches GitHub anchors.

  fails with the documented capacity error; operator pruning is the recovery path.
- `importSnapshot` with an explicit empty event log keeps prior in-memory events. The store always
  imports into a fresh graph, so there is no persisted effect; left unchanged.
