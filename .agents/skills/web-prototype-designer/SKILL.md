# Web Prototype Designer

Design and implement complete, responsive, and visually distinctive web prototypes with curated aesthetic systems.

## Supported Aesthetic Archetypes (`--style`)

### 1. Neo-Brutalist (`brutalist`)
- High contrast, thick solid black borders (`2px - 3px solid #000`), hard drop shadows with zero blur (`box-shadow: 4px 4px 0px #000`).
- Vibrant punchy accents (electric yellow `#FFE600`, vivid cyan `#00F0FF`, hot magenta `#FF0055`) on stark white or cream canvas.
- Monospace or bold condensed neo-grotesque typography (`Space Mono`, `Syne`, `Archivo Black`).

### 2. Archival Editorial (`editorial`)
- Refined serif typography for headlines (`Playfair Display`, `Fraunces`, `Cinzel`) paired with clean mono accents (`IBM Plex Mono`).
- Warm neutral paper backgrounds (`#FBF9F5`, `#F4F0EA`), delicate divider lines, generous white space, and asymmetric multi-column layouts.

### 3. Soft Bento (`soft`)
- Gentle pastel palettes (lavender, soft mint, blush pink), smooth layered shadows (`box-shadow: 0 10px 30px -10px rgba(0,0,0,0.05)`), rounded container corners (`rounded-2xl` / `rounded-3xl`).
- Micro-interactions with spring easings.

### 4. Minimalist Clean (`minimal`)
- Warm monochrome palette, subtle hairline borders (`1px solid #E5E7EB`), flat modular bento grids, strict typographic contrast without gradients.

### 5. Modern Dark Glass (`glass`)
- Deep neutral backdrop (`#09090B`, `#0D1117`), translucent frosted card shells (`backdrop-blur-md bg-white/5 border border-white/10`), crisp accent glows and subtle dot matrices.
