Nothing here is part of a runtime package or CI input.

- `RECOVERY-PLAN.md` — completed September 2026 recovery plan; its origin commit, task queue,
  and gate status are obsolete.
- `bug-swarm/` — historical September 2026 findings, fixes, and coding-agent feedback. Several
  findings were superseded by later commits, so use current source and tests as the source of
  truth.
- `working-notes/plan-targets.txt` and `working-notes/tier-paths.txt` — unreferenced planning
  lists with no active script consumer. Retained for traceability.

The ignored `.data/`, `.performance-optimization/`, `JEV-Family/`, and `artifacts/` trees were
left in place because they contain deliberate local state, research checkouts, or evidence.
